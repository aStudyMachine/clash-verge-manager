# 使用 TypeScript 核心，正式发行不依赖 Python

2026-10-21，用户提出后续考虑长期维护并向其他用户开放软件，在重新评估技术取舍后明确接受 Electron + React + TypeScript/Node.js 核心，正式发行不依赖 Python。原先保留 Python 主要为了尽快复用部署逻辑；当前配置解析、文件事务、版本同步及稳定池评估未发现必须依赖 Python 的专属能力，统一核心可减少跨语言模型、运行环境与发行链路的维护。

代价是需要迁移现有实现，并以备份、并发、崩溃恢复、运行核验和稳定池决策等行为契约验证。Python 实现可留作开发期参照；Windows 专有功能集中到本机适配模块，必要的辅助程序随包交付，不能因此把正式运行依赖藏回 Python 任务中。领域核心保持独立于 Electron 和 Windows，以便单独测试和长期演进。
