# 采用配合 Clash Verge 的独立配置管理器

2026-10-21，用户在设计访谈第一轮确认采用独立配置管理器：集中维护订阅、节点、代理组和规则，将结果应用到 Clash Verge；代理运行、TUN 和系统代理继续由 Clash Verge 承担。与重新实现完整代理客户端相比，此边界直接对应日常配置维护的目标，并允许复用仓库既有的部署、校验和恢复能力。

首版面向个人多设备使用，编辑采用聚合配置草稿后统一应用。配置权威源随后由 [ADR 0002](0002-manager-owned-editable-configuration.md) 确认；订阅统一管理以能够应用生效为前提，后续集成、跨设备同步及正常退出限制见[完整方案](../design/subscription-manager-plan.md)。
