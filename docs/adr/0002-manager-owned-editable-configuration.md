# 由配置管理器持有可编辑配置

2026-10-21，用户确认以新软件保存的配置为准，并支持脱离当前代码仓库使用。相比让软件仅成为仓库 JSON 与 Script 的编辑界面，该选择需要将现有生成和部署能力与固定仓库布局解耦，但更符合通过独立软件完成日常管理的目标。

同一受管聚合配置不能同时由新软件和旧仓库同步入口相互覆盖。后续第三轮已确认跨设备共享订阅参与关系、节点筛选、代理组、场景和规则，凭据、端口、TUN、当前选择及健康状态分别留在本机；第四轮通过 [ADR 0003](0003-private-git-configuration-sync.md) 确认私有 Git 同步渠道。本机稳定来源映射、接管时切换专属扩展绑定、旧入口拒绝覆盖及显式反向交还的契约见[完整方案](../design/subscription-manager-plan.md)。
