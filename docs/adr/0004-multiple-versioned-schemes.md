# 多套方案独立保存，同方案按版本覆盖

2026-10-21，用户明确要求支持多方案，首次只有 `default`，沿用 `YYYY.MM.DD.序号` 版本号设计，同一方案以较新版本覆盖较旧版本。与同步冲突时让用户逐次选择两份完整配置相比，此决定将方案版本作为同步新旧关系的依据，需要将当前单份聚合配置的版本模型推广到每套方案。

不同方案互不覆盖，最后上传时间不作为方案版本的替代物。第六轮进一步确认：离线可编辑、应用本地草稿，在线上传时才依据共享端当前版本分配更高正式版本；并发发布重新取号，历史保留。同版同内容视为一致，同版异内容视为异常，不自动合并不同设备的内容；因此后发布的旧草稿也可能替换另一台设备已发布的修改。

来源订阅和节点库全局共用，各方案独立保存配置设计。Clash Verge 只保留一个受管聚合入口，明确应用后才切换其内容；已发布版本与设备实际应用状态分开记录。外部受管修改可显式导入草稿并发布，否则下次应用恢复软件方案，普通节点手选仍属于本机状态。
