# 使用独立私有 Git 仓库同步脱敏配置

2026-10-21，用户确认由配置管理器封装上传和获取操作，使用独立保存脱敏配置的私有 Git 仓库同步多台设备的配置设计。相比手动传递文件或依赖网盘同步目录，该选择能保留版本历史，代价是需要处理仓库接入、认证及并发修改；日常操作不要求用户维护代码仓库。

共享范围沿用已确认边界：配置设计参与同步，订阅凭据、端口、TUN、当前选择和健康状态分别留在本机。远端配置获取后经检查和应用才影响代理；第五轮由 [ADR 0004](0004-multiple-versioned-schemes.md) 确认多方案独立保存、同方案按版本覆盖。后续确认在线发布取号及并发重试，幂等发布和来源目录一致性契约见[完整方案](../design/subscription-manager-plan.md)。
