# 第三方运行资源

- Electron、Chromium、Node.js：通过 Electron 官方发行包交付，保留发行包自带的许可证与第三方说明。
- MinGit：来自 Git for Windows 官方发行，来源、版本与 SHA-256 见同目录运行资源锁。发行时保留 MinGit 包内许可证与说明；上游项目为 https://gitforwindows.org/。
- 界面及核心依赖：React、YAML、Zod、ipaddr.js，版本由软件依赖锁确定；对应许可证随应用依赖交付。
- 场景预设数据：由内置场景规则模板整理，预设逐项记录来源和版本。公开发行前须核对所分发数据的来源与许可范围。
